// MACHINE LEARNING CASE STUDY

Review Fraud Detection

An NLP-powered pipeline analyzing client reviews to flag anomalous behaviors and artificial reviews using a high-consensus multi-classifier voting network.

F1-Score: 91.8% Ensemble consensus

1. The Problem

Online product review platforms are frequently targeted by artificial campaigns designed to distort consumer perceptions. These deceptive reviews often mimic human-written text structural patterns, rendering standard keyword filtering algorithms ineffective. A single-model ML classifier struggles to generalise across varied deception styles, resulting in high false-positive rates that disrupt legitimate system reviews.

2. My Approach

I developed a multi-stage Natural Language Processing (NLP) pipeline built on Python and Scikit-learn. The text dataset undergoes pre-processing (stop-word removal, tokenization, lemmatization) before feature extraction using N-gram configurations and TF-IDF vectors. To achieve balanced generalization, I implemented a VotingClassifier configured with a soft-voting scheme, aggregating predictions from Support Vector Machines (SVM), Naive Bayes, and Logistic Regression algorithms.

4. Key Challenges & Resolutions

Challenge: TF-IDF extraction over wide vocabularies resulted in extremely high-dimensional matrices, slowing classification times during predictions.
Resolution: Set explicit max-feature boundaries inside TF-IDF vectorization configurations and utilized N-gram ranges limited to (1, 2) word patterns. This optimized model parameters without sacrificing linguistic performance metrics.

Challenge: Individual models, such as Naive Bayes, showed systematic classification bias toward shorter text blocks, causing elevated false positive rates.
Resolution: Constructed a soft-voting ensemble mechanism. Weight coefficients were optimized based on individual model testing, allowing SVM and Logistic Regression predictions to counter-balance Naive Bayes bias.

5. Results & Metrics

Algorithm Precision Recall F1-Score
Naive Bayes 84.2% 81.0% 82.5%

Voting Classifier (Ensemble) 91.8% 90.2% 91.0%

The ensemble Voting Classifier achieved a 91.8% precision rating and 91.0% total F1-Score, outperforming any standalone statistical classifier.
